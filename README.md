# Muon vs AdamW на nanoGPT

Групповой проект по курсу Deep Learning. Мы исследуем, как оптимизатор Muon влияет на обучение небольшой языковой модели, и сравниваем его с AdamW по качеству и скорости обучения.

За основу взят [modded-nanogpt](https://github.com/KellerJordan/modded-nanogpt/tree/d6a58a321d459a9267243aecc3e0615cffc8f2fc). Мы планируем провести сравнение на уменьшенных моделях и проверить, как результат меняется с их размером.
