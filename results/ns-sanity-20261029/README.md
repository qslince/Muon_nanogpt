# Проверка Newton–Schulz на сервере команды

Дата: 29 октября 2026 года. Пользователь сервера: `aleksei`.

## Окружение и запуск

- Python 3.12.3, PyTorch 2.10.0+cu128, NumPy 2.2.6.
- Личное окружение: `/home/aleksei/venvs/project`.
- GPU: NVIDIA GeForce RTX 4080 SUPER.
- Коммит репозитория: `584f0098ea088ce395f80339559cff5f3b1e979c`.
- Проверка запущена в tmux; CUDA-команда выполнена через общую очередь `gpu-run`.
- Результаты на сервере: `/home/aleksei/results/ns-sanity-20261029T110055Z`.
- Сохранены версии пакетов, хеши исходного файла и скрипта, настройки и полные спектры.
- Рабочее дерево репозитория перед запуском было чистым.

Команды из корня репозитория, при активированном личном окружении:

```bash
python scripts/check_newton_schulz.py --device cpu --dtypes fp64 fp32 bf16 fp16 --output-dir "$HOME/results/NEW_RUN/cpu"
gpu-run python scripts/check_newton_schulz.py --device cuda --dtypes fp64 fp32 bf16 fp16 --output-dir "$HOME/results/NEW_RUN/cuda"
```

`NEW_RUN` нужно заменить новым именем: скрипт не перезаписывает результаты.

## Сравнение CPU и GPU

Входные спектры в двух серверных запусках совпали точно. Скрипт и исходный файл
были одинаковыми. Ниже максимальная абсолютная разница соответствующих выходных
сингулярных значений по всем проверенным матрицам и числам итераций:

| Точность | Максимальная разница CPU/CUDA |
|---|---:|
| FP64 | 1.42 × 10⁻¹³ |
| FP32 | 8.46 × 10⁻⁵ |
| BF16 | 1.85 × 10⁻² |
| FP16 | 1.99 × 10⁻² |

Это сравнение спектров, а не относительная ошибка матриц и не оценка качества
обучения. Низкая точность заметно влияет на некоторые плохо обусловленные и
неполноранговые входы. Например, для плохо обусловленной матрицы 16×16 после
5 итераций BF16 относительная ошибка матрицы относительно FP64 составляет около
0.536. Успешное сравнение с исходной BF16-функцией подтверждает совпадение
реализаций, но не близость BF16 к FP64 во всех случаях.

С предыдущим локальным CPU-запуском тоже проведено сравнение: хеш скрипта
совпадает. Локально использовался PyTorch 2.15.0+cpu и Windows, поэтому различия
между ним и серверным запуском нельзя приписывать только GPU. Контролируемое
сравнение выше использует CPU и GPU одного серверного окружения.

## Границы вывода

Проверен матричный алгоритм на синтетических данных. Проверки реальных направлений
обновления после momentum, скомпилированной функции и абляция при обучении GPT
остаются отдельными задачами. По этой проверке нельзя заключить, что Muon быстрее
AdamW или что все выходные сингулярные значения обязаны попасть в [0.7, 1.2].

Результаты подготовлены и проанализированы с помощью Codex.
